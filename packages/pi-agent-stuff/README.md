# Pi Agent Stuff

Small, general-purpose Pi resources that are easier to maintain and install as one package.

## Extensions

- `add-dir`: adds session-scoped working directories and `@` completion.
- `claude-rules`: loads unscoped project rules from `.claude/rules/`.
- `continue`: sends a literal continuation prompt while Pi is idle.
- `prompt-stash`: transfers an unsent editor draft to and from one branch-local stash slot.

## Skills

- `eli5`
- `handoff-herdr`
- `write-docs`

Install this package instead of the Water root when only these general resources are needed. Do not install both, because Pi would load the same resources twice.
